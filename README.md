🏁 Project Description – Line Following Robot for MCR Competition
This project was developed as part of the Microcontroller Robot Contest (MCR), a competition that challenges students to build and program autonomous robots using embedded systems. Inspired by Japanese-style line tracing competitions, the goal was to design a robot capable of following a black line on a white surface with high accuracy and speed.

The robot was entirely coded by myself using C for embedded microcontrollers. The system integrates multiple infrared sensors to detect the line and uses a PID control algorithm for smooth and responsive navigation. The main focus was on optimizing line detection, motor control, and handling sharp turns and intersections.

Key features include:

🔧 Custom PID tuning for line tracking stability

👀 Real-time sensor reading and edge detection

⚡ Fast response motor control using PWM

🛞 Precise turning logic for corners and U-turns

The robot successfully completed the MCR challenge track with consistent performance and high reliability.
